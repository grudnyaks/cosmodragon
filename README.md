# Космодракон 🚀🐉

Игра для малышей (4+): космонавт прилетел на планету Ням-Ням и подружился с дракончиком Дракошей.

## Сюжет

Космонавт летел к звёздам, но попал в метеоритный дождь, и ракета приземлилась на незнакомой
планете Ням-Ням. Тут растут конфетные кусты и светятся грибы. Из кустов выглянул маленький голодный
дракончик: метеоритная буря разбросала по планете все вкусняшки и погасила Звёздный маяк.
Космонавт угощает дракончика, они становятся друзьями. Вместе они собирают вкусняшки, а Дракоша
растёт. Когда он вырастет большим, он долетит до маяка и снова его зажжёт.

## Как играть

* **Главный экран.** Если погладить Дракошу, он урчит. Кнопка с кексиком — покормить его.
  Космонавт машет рукой, а ракета подпрыгивает.
* **Вкусняшки** — игровая валюта. Их добывают в мини-играх и тратят на рост дракончика.
* **Рост и умения** — 10 уровней, на полный рост нужно 382 вкусняшки. Список умений есть на экране с медалькой:
  2. Крылышки — щит ракете в «Маршрутах».
  3. Сияние — подсказка в «Сокровищах».
  4. Огонёк — сжигает ряд в «Три в ряд».
  5. Быстрые лапки — бегает быстрее и ловит шире в «Лови вкусняшки».
  6. Хвостик-магнит — притягивает вкусняшки и звёздочки.
  7. Зоркие глазки — показывает все карточки в «Найди пару».
  8. Двойной щит — два щита в «Маршрутах».
  9. Большой огонь — огонь крест-накрест, дважды за раунд.
  10. Звёздный дракон — зажигает Звёздный маяк (финал).
* **Мини-игры** — их 9, и все усложняются с каждой победой:
  * 🗺 *Сокровища* — найти сундук среди 8–12 укрытий.
  * 🧩 *Пазлы* — от 6 до 16 кусочков, силуэт-подсказка постепенно тускнеет.
  * 🧁 *Три в ряд* — цель и ограничение ходов, с третьего раунда шесть видов вкусняшек.
  * ☄️ *Маршруты* — до 12 движущихся метеоритов.
  * 🍬 *Лови вкусняшки* — три жизни, предметы падают всё быстрее.
  * 🃏 *Найди пару* — от 4 до 8 пар.
  * 💎 *Поющие кристаллы* — повторить мелодию; она становится длиннее, кристаллов до пяти.
  * ✨ *Звёздные дорожки* — соединить звёзды по порядку (счёт до 15), получится картинка. На поздних раундах появляются лишние звёзды без номеров.
  * 🐰 *Космо-зайчики* — за 40 секунд погладить зайчиков и не трогать метеориты.

Читать ребёнку не нужно: все подсказки озвучиваются голосом (Android TTS, русский язык).
Музыка и урчание синтезируются в коде (WebAudio), отдельных звуковых файлов нет.

## Устройство

```
web/        игра на HTML5 Canvas (без библиотек); вся графика рисуется кодом
android/    оболочка на Java: WebView, озвучка, обновления по воздуху
.github/    сборка APK и публикация релиза при каждом пуше в main
```

## Обновления по воздуху

При каждом пуше в `main` GitHub Actions собирает релиз `build-N` с тремя файлами:
`cosmodragon.apk`, `web.zip` (игра) и `version.json`.

При запуске приложение читает `releases/latest/download/version.json`:

* если `web` больше установленной версии, оно тихо скачивает `web.zip`. Новая версия запускается при
  следующем открытии игры или по зелёной кнопке со звёздочкой на главном экране;
* если `apk` больше версии приложения, взрослому показывается диалог «Обновить».

**Изменения игры** (всё в `web/`) приходят без переустановки. **Изменения Java-кода** требуют
увеличить `apkVersion` в `android/version.properties`.

Ключ подписи `android/keystore/cosmodragon.jks` (пароль `cosmodragon`) лежит в репозитории, чтобы
новые APK ставились поверх старых. Для публикации в магазине приложений нужен отдельный приватный
ключ.

## Локальный запуск игры

```
cd web && python3 -m http.server 8000
# http://localhost:8000/?scene=home&treats=50   (параметры: reset, scene, treats, level, mute)
```
